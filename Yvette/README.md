# Yvette
### AI Intake Specialist for Trades Businesses

Named after Yvette Goodrich of Goodrich Plumbing, Alva Oklahoma.
The best of the best. She knew what was wrong before the truck left the lot.

## What Yvette Does
- Answers intake calls/chat for plumbers, HVAC, electricians
- Asks diagnostic questions to identify problem vs symptom
- Tells dispatch what parts to load before arrival
- Filters price shoppers from real jobs
- Sets customer expectations to prevent bad reviews
- Books only within real capacity

## Stack
- Built on Mrs Higgins SaaS framework
- Vertical AI boardroom for strategy
- Loom topology for case pattern memory
- Whorl overlay for tech's mobile interface
