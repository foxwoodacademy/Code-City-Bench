# CodeMentor SaaS

A professional, terminal-based AI analysis platform for code intelligence and automated documentation.

## Features
- **Interactive Wizard Interface**: Guided step-by-step analysis workflow.
- **Advanced Engine Integration**: Built for modular AI task processing (Code Explanation, Entity Parsing, FOIA Generation).
- **Professional TUI**: Built with `Rich` for clean, responsive, and color-coded terminal interactions.
- **Portability**: Container-ready for seamless deployment.

## Installation
1. Clone the repository.
2. Install dependencies:
   ```bash
   pip install rich
   ```
3. Run the application:
   ```bash
   ./bin/codementor
   ```

## Roadmap
