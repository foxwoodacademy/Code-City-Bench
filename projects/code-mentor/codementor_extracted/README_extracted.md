# Implore: Grant Intelligence CLI

Implore is an autonomous CLI tool for developers to scan codebases and auto-generate grant applications.

## Usage
1. Install requirements: `pip install requests`
2. Run pipeline: `python3 implore.py <directory>`
3. Review results: `implore_application.json`
