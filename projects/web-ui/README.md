# Web-UI Project

This project contains various UI experiments, prototypes, and landing pages for the RootBase ecosystem.

## Components

- **Landing Pages:** `index.html`, `marketplace.html`, `project.html`
- **Dashboards/Visualizations:** `boardroom_minimal.html`, `substrate_boardroom.html`, `syntax_pitch.html`
- **Experimental/Utility:** `brainbleed.html`, `chew_plumbing.html`, `evolution.html`, `gap_wall.html`, `whorl.html`

## Usage

These are static HTML/CSS files and can be opened directly in any modern web browser.
