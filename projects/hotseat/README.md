# Hotseat: Technical Advisory Session

Hotseat is a lightweight, agentic-powered technical advisory CLI tool designed for developers working on recursive self-improvement engines and agentic systems.

## Prerequisites

- `GROQ_API_KEY` must be set in your environment.
- `bash`, `curl`, and `python3` must be installed.

## Usage

Run the advisory session:

```bash
./hotseat_claude.sh
```

Follow the prompts to ask technical questions.
