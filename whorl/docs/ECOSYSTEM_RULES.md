# Whorl Ecosystem Rules & Prerequisites

## Agent Advancement
Agents advance tiers based on sustained fitness and successful completion of Data Campus objectives.

## Tier Prerequisites for Molt RIE Access
- **BRONZE**: No autonomous access. Limited to external refinement via Orchestrator.
- **GOLD**: Conditional access. Requires accumulation of 5 'Molt Credits' (earned through swarm cooperation).
- **PLATINUM**: Full autonomous access. Granted to agents demonstrating independent threat neutralization and consistent high fitness.

## Data Campus Incentives
1. **High-Fidelity Context Access**: Platinum agents gain read/write access to deeper Hivemind history nodes.
2. **Kernel Expansion**: Platinum agents gain the ability to initialize sub-processes in custom kernels (beyond standard Bash/PS/Python).
