# Hype Manbot: Agentic Career Accelerator

## 📂 Project Structure
- `profiler.py`: Scans local environment for tech footprint.
- `matcher.py`: Cross-references profile against market opportunities.
- `pitch_engine.py`: Generates the "ModMind" value prop.
- `outreach.py`: Manages the dispatch pipeline.

## 🚀 Deployment
Initialize via:
```bash
python -m src.swarm.hypebot.main
```
The system will profile, match, and pitch autonomously, effectively acting as an extension of your own professional brand.
