# Whorl: The Cross-Platform Execution Runtime

Whorl is the agnostic runtime for the RootBase agentic swarm. It provides a standardized interface for executing swarm commands across Linux, Windows (PowerShell), and heterogeneous environments.

## 📁 Repository Structure
- `linux/`: Native bash-based runtime implementation.
- `powershell/`: Native PowerShell runtime implementation.
- `docs/`: Technical specification and integration manual.

## 🚀 Design Principles
- **Agnostic:** The runtime does not assume the environment.
- **Peer-Reviewed:** Code prioritized for readability, type safety, and security.
- **Interoperable:** Standardized JSON interface for all language extensions.
