# Hype Manbot: Talent Accelerator & Matchmaker

## Core Role
The Hype Manbot is your personal agentic PR firm. It continuously monitors the developer's output (logs, commits, project completions), builds a "Hype Profile," and identifies high-fit companies based on tech stack, culture, and project needs.

## Key Features
1.  **Attribute Profiler:** Analyzes technical artifacts and extracts core competencies.
2.  **Market Matchmaker:** Scans for companies that align with the developer's growth goals and stack.
3.  **Hype Engine:** Generates high-impact "pitch" content for profiles, resumes, and networking outreach.
4.  **Concierge Handoff:** Pre-screens matches, acting as a buffer to ensure only premium connections reach the dev.

---

# Agent Concepts: Concierge & Valet

## 1. Concierge (The High-Level Orchestrator)
- **Role:** Direct interface for the user. Takes high-level intent ("I want a new job", "I need to learn X") and delegates to the specialized swarm (HypeBot, Researcher, etc.).
- **Focus:** User experience, prioritization, and maintaining long-term objectives.

## 2. Valet (The Low-Level Enabler)
- **Role:** Handles the tedious background tasks required to keep the dev environment and agents moving. 
- **Focus:** Environment cleanup, secret rotation, managing local AI model availability, and log archiving.
