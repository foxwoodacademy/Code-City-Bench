# Vertical Radar

A FOSS-based, modular vertical AI swarm for automated risk assessment.

## Project Structure
- `src/radar/`: Core swarm agents and orchestration logic.
- `src/tools/`: FOSS scraping and search tools.
- `src/data/`: Persistent state and historical reports.

## Getting Started
1. Install dependencies: `pip install langchain langgraph duckduckgo-search trafilatura beautifulsoup4`
2. Run the swarm: `python3 -m src.radar.main`
