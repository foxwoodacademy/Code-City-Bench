Data Model (PostgreSQL)
We store documents, extracted entities, and analysis results in relational tables. Key models include:
Document: stores metadata for each uploaded file. Fields might include id, filename, upload_time, doc_type (text/PDF/JSON/CSV), status (e.g. PENDING, ANALYZED), and possibly a file path or raw text field.
NamedEntity: stores entities extracted by spaCy. Fields: id, document_id (FK), entity_text, entity_type (e.g. PERSON, ORG, DATE, CASE_ID), start_offset, end_offset (positions in text), etc.
AnalysisResult: stores the outcome of the misconduct analysis. Fields: id, document_id (FK), risk_score (numeric), misconduct_type (categorical, e.g. CIVIL-RIGHTS, RICO, COLLUSION), summary_markdown (a short Markdown summary of findings), created_at, etc.
FlaggedEntity (optional): links AnalysisResult to specific entities/phrases that triggered alerts. Fields: id, result_id (FK), entity_text, entity_type, matched_pattern (which rule was hit).
These can be implemented in SQLAlchemy as follows (simplified example):

Flask API Endpoints
We expose RESTful endpoints for uploading documents, triggering analysis, and fetching results. Example routes:
POST /api/documents – Upload a new document. Accepts file content (multipart/form-data) or raw text/JSON/CSV in the request. On success, it creates a new Document record (status PENDING) and returns its ID.
POST /api/documents/<int:doc_id>/analyze – Manually trigger analysis for an uploaded document. This enqueues a Celery task to process the document asynchronously. Returns a JSON response with status and doc_id.
GET /api/documents/<int:doc_id>/results – Fetch analysis results. Returns structured JSON (see below) with flagged entities, risk score, misconduct type, and summary. Returns 404 if results are not yet ready.
For example, in Flask we might define:
from flask import Flask, request, jsonify, abort
from models import db, Document, AnalysisResult
from tasks import analyze_document_task

app = Flask(__name__)
db.init_app(app)

@app.route('/api/documents', methods=['POST'])
def upload_document():
    """
    Upload a document for analysis. Accepts PDF/text/JSON/CSV and
    stores it before queuing analysis.
    """
    file = request.files.get('file')
    text = request.form.get('text')
    # Determine type and extract text
    if file:
        text_content = extract_text_from_file(file)  # implement PDF/text parsing
        doc_type = 'PDF' if file.mimetype == 'application/pdf' else 'TEXT'
    elif text:
        text_content = text
        doc_type = 'TEXT'
    else:
        return jsonify({"error": "No input provided"}), 400

    # Save document
    doc = Document(filename=file.filename if file else None, doc_type=doc_type, text_content=text_content)
    db.session.add(doc); db.session.commit()
    return jsonify({"doc_id": doc.id, "status": "uploaded"}), 201

@app.route('/api/documents/<int:doc_id>/analyze', methods=['POST'])
def trigger_analysis(doc_id):
    """
    Trigger parsing and analysis of the given document in background.
    """
    doc = Document.query.get(doc_id)
    if not doc:
        abort(404, description="Document not found")
    # Enqueue a Celery task for processing
    analyze_document_task.delay(doc_id)
    doc.status = 'ANALYSIS_QUEUED'
    db.session.commit()
    return jsonify({"doc_id": doc_id, "status": "queued"}), 202

@app.route('/api/documents/<int:doc_id>/results', methods=['GET'])
def get_results(doc_id):
    """
    Retrieve analysis results (flagged entities, risk score, summary, etc.).
    """
    result = AnalysisResult.query.filter_by(document_id=doc_id).first()
    if not result:
        abort(404, description="Results not available")
    # Build JSON output
    data = {
        "doc_id": doc_id,
        "risk_score": result.risk_score,
        "misconduct_type": result.misconduct_type,
        "summary": result.summary_markdown,
        "flagged_entities": [{"text": f.entity_text, "type": f.entity_type} 
                             for f in result.flagged_items]
    }
    return jsonify(data)

Asynchronous Processing with Celery
We use Celery tasks for heavy-lifting. For example, analyze_document_task will:
@celery.task
def analyze_document_task(doc_id):
    """
    Celery background task to process a document:
    extract text, parse entities, run pattern-matching, and save results.
    """
    doc = Document.query.get(doc_id)
    if not doc:
        return
    # 1. Ensure we have raw text (it might have been extracted on upload)
    text = doc.text_content or extract_text_from_file(doc.filename)
    doc.text_content = text
    db.session.commit()

    # 2. NLP parsing
    nlp_doc = nlp(text)
    # Save named entities
    for ent in nlp_doc.ents:
        ne = NamedEntity(document_id=doc_id, entity_text=ent.text, entity_type=ent.label_,
                         start_offset=ent.start_char, end_offset=ent.end_char)
        db.session.add(ne)
    db.session.commit()

    # 3. Red-flag rule matching (as described above)
    flagged = []
    # (Assume matcher has been set up globally)
    for match_id, start, end in matcher(nlp_doc):
        rule_name = nlp.vocab.strings[match_id]
        span = nlp_doc[start:end]
        flagged.append((rule_name, span.text))
        f = FlaggedEntity(analysis_id=None, entity_text=span.text,
                          entity_type='PHRASE', matched_rule=rule_name)
        db.session.add(f)
    db.session.commit()

    # 4. Compute risk score and summary
    score = compute_risk_score(flagged)  # custom logic
    misconduct_type = classify_misconduct(flagged)  # e.g. returns "CIVIL-RIGHTS" or "RICO"
    summary = generate_summary(flagged)  # e.g. a Markdown bullet list or paragraph

    # 5. Save analysis result
    result = AnalysisResult(document_id=doc_id, risk_score=score,
                            misconduct_type=misconduct_type, summary_markdown=summary)
    db.session.add(result)
    db.session.commit()

    # Link flagged items to this result
    for f in FlaggedEntity.query.filter_by(analysis_id=None, entity_text=f.entity_text):
        f.analysis_id = result.id
    doc.status = 'ANALYZED'
    db.session.commit()

Our rule engine is modular and data-driven. We store misconduct schemas (rule sets) outside the code (e.g. JSON files or a database table).
