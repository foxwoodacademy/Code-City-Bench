```bash
Find and list hidden MP4 video files

   → d

   ./.hidden_video1.mp4

2. List with details
   Command: find . -name ".*.mp4" -type f -exec ls -lh {} \;

3. Count how many
   Command: find . -name ".*.mp4" -type f | wc -l

🔗 RELATED COMMANDS:
  • find . -name "*.mp4" -type f
  • ls -lha *.mp4
  • du -sh .*.mp4

------------------------------------------------------------

====================================================================
🎯 HOW TO: PLAY HTML FILES
====================================================================

Open HTML files in browser

📋 STEPS:

1. Find HTML files
   Command: find . -name "*.html" -type f

2. Open in browser (Termux)
   Command: termux-open file.html

3. View source code
   Command: cat file.html

💡 Note: On Termux, install termux-tools package first
```

## How It Works

### Frustration Tracking:
```python
User: "find mp3"          # No match
  → frustration_level = 1

User: "wtf this sucks"    # Keywords detected
  → frustration_level = 2

User: "fuck this"         # More frustration
  → frustration_level = 3
  → TRIGGERS AUTO-INTERVENTION
```

### Easter Egg Detection:
```python
if "rage quit" in query:
    offer_cathartic_options()
elif "am i stupid" in query:
    reassure_user()
elif "matrix" in query:
    run_eye_candy()
```

### Success Resets Frustration:
```python
User successfully finds command
  → frustration_level -= 1
  → failed_queries.clear()
```
