1. **Sweep (The Chronos Pass)**:

2. **Audit (The Rhea Pass)**:
   - Compare folder contents against the `SATURN.md` index.

3. **Upgrade (The Zeus Pass)**:
   - Auto-update `requirements.txt` across all labs.
   - Refactor outdated syntax to the latest project standard.
   - Suggest merges for fragmented versions.

4. **Archive (The Hades Pass)**:
   - Move flagged entropy to `archive/` with a timestamped manifest.
