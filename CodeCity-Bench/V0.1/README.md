# CodeCity-Bench

CodeCity-Bench is a professional-grade, modular, and portable "workbench" for code analysis, visualization, and topological data compression. 

It moves beyond the gamified "Code City" concept, providing a "toolbag" of specialized components for deep structural understanding of software.

## Core Pillars

- **Portability (Toolbag):** Modular components (Scanners, Visualizers, Loom engine) designed for easy integration and portability.
- **Compression (Loom):** A mathematical engine that uses "celtic knotwork topography" to map code structure into a compact, 3D topological surface.
- **Modular Workbench:** A high-end, professional developer interface for deep code exploration.

## Project Structure

- `src/core/loom/`: The mathematical and topological engine.
- `src/core/scanners/`: Modular code analysis engines.
- `src/visualizers/`: 3D and 2D data representation tools.
- `src/api/`: Integration layers.
- `tests/`: Unit and integration tests.
- `docs/`: Technical documentation.
