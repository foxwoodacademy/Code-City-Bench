## 5. Tmux Command Citadel: Operational Guide
To launch your entire ModMind Swarm Command Center, execute the following alias:

```bash
start_swarm
```

This will open a `tmux` session named `ModMindSwarm` with the following windows and panes:

### Window 0: THOTH_UI (Main Control)
- **Purpose:** Your primary interactive console for Thoth.
- **Interaction:** Type commands directly into the prompt (e.g., `a` for audit, `r` for revenue, `e` for escalate, `q` to quit the UI).

### Window 1: MONITOR (Real-time Logs)
- **Purpose:** Live feeds from the core swarm services.
- **Panes:**
    - Top-Left: `tail -f /storage/emulated/0/RootBase/lough_system/lough.log` (Lough Event Spine)
    - Bottom-Left: `tail -f /storage/emulated/0/RootBase/web_server/websocket.log` (Dashboard Heartbeat)
    - Right: `tail -f /storage/emulated/0/RootBase/nursery/molt.log || tail -f /storage/emulated/0/RootBase/swarm_motion.log` (Molt Engine & Swarm Activity)
- **Interaction:** Monitor output. No direct input needed here.

### Window 2: THOTH_CLI (Direct Command Line)
- **Purpose:** A dedicated shell for direct Thoth CLI commands, running in `--watch` mode.
- **Interaction:** Execute Thoth commands directly (e.g., `python3 /storage/emulated/0/RootBase/thoth_orchestrator/thoth.py --revenue --platform Nostr`).

### Window 3: AGENT_SHELLS (Vibe/Codex Interaction)
- **Purpose:** Interactive shells for direct control of Vibe and Codex.
- **Panes:**
    - Left: Vibe CLI (for targeted scouting, ingestion commands)
    - Right: Codex CLI (for refactoring, skill registration, troubleshooting)
- **Interaction:** Type commands for Vibe or Codex as needed.

### Window 4: SYSTEM_MONITOR (Resource Oversight)
- **Purpose:** Real-time system resource monitoring.
- **Interaction:** Observe CPU, memory, and process usage via `htop`.

### Tmux Navigation Commands:
- `Ctrl+b + <number>`: Switch to window number `<number>` (e.g., `Ctrl+b 0` for THOTH_UI).
- `Ctrl+b + n`: Go to the next window.
- `Ctrl+b + p`: Go to the previous window.
- `Ctrl+b + %`: Split the current pane vertically.
- `Ctrl+b + "`: Split the current pane horizontally.
- `Ctrl+b + arrow keys`: Move between panes.
- `Ctrl+b + z`: Zoom current pane to full screen (press again to unzoom).
- `Ctrl+b + d`: Detach from the `tmux` session (session keeps running in background).
- `tmux attach -t ModMindSwarm`: Reattach to the session if detached.

**To make the alias active, you must either:**
1.  **Restart your Termux session.**
2.  **Source your .bashrc:** `source ~/.bashrc`
